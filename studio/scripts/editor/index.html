点下面的小词选它（Shift+点 选一段），按 X 剪掉 / 还原 · 双击小词从那里播放，空格 播放 / 停 · Ctrl+Z 撤销，Ctrl+Y 重做 · Delete 删整句（字幕和声音，再按还原） · ↺ 还原这一句＝回到自动的样子 · 在声音图上拖一段：X 剪掉，R 放回去，Esc 取消选取 · 点字幕改字，Enter 确定（〔〕里的字＝剪掉） · 把小词拖到上一句或下一句，就把它移过去 · 灰色虚线的词＝影片里没用到；橙色虚线的词＝听得到但字幕里没有，点一下写进字幕。灰色的词勾「听原声」能听到，点一下就放回影片（点绿色的＋字可以改字） · Ctrl+S 保存（存进字幕表，下次出片就用）
字幕里的符号：/（或 ／）＝在这里分成两条字幕，可以用几次分成几条 · ＋（或 +）放在字幕最后＝跟下一条接成一条，放在最前面＝跟上一条接成一条（不同录音、中间隔一行、拖不过去的时候用） · 〔〕 或 [ ]＝剪掉这段声音 · （）＝给剪辑的备注，不会出现在字幕
