# Vlog Studio

[English](README.md) · **中文**

这是一个 Claude Code 插件，用你自己拍的素材做旅行 vlog 和实地影片。剪辑团队的工作由 Claude 来做，你当导演：你负责拍、讲你那一天的事、看初剪、说哪里要改。不用写程序。

它可以做**横的影片（16:9）、直的影片（9:16：Reels、Shorts、TikTok），或者同一趟旅行两种都做**，并且替你发的每一个平台各写一份上传文字，因为每个平台的规则不一样。

它原本是跟频道「金釘子 GoldenSpike」一起、在真实的旅行里做出来的，后来整理成任何语言、任何旅行都能用。它跟 [Explainer Studio](https://github.com/yuxuanteh/explainer-studio)（棚拍讲解加动画）是两个分开的插件，互不相干，可以同时安装。

## 安装和开始：一段话就够

在 Claude Code（终端机、桌面版或 IDE 扩充都可以）里开一个资料夹当你的频道资料夹，把下面这段贴进去，最后几行换成你自己的：

```text
帮我安装 Vlog Studio 插件，并把我的 vlog 工作室设好。
1. 在终端机执行：claude plugin marketplace add yuxuanteh/vlog-studio
   接着执行：    claude plugin install vlog-studio@vlog-studio
2. 找到装好的插件资料夹（在 ~/.claude/plugins 底下），读里面的 skills/vlog-setup/SKILL.md，一步一步照着做。
   先检查我的电脑，告诉我每个步骤大概要多久。问我做横的影片、直的影片，还是两种都做，还有我发在哪些平台。
   要安装或下载任何东西之前，先告诉我它是做什么的、有多大，问我需不需要。
3. 工作室设好之后，用我自己的几段素材跟我试跑一次。
我的频道：<名字>。我做<横的 vlog / Reels 和 Shorts / 两种都做>，发在<YouTube、Instagram、TikTok……>。
我用<相机 / 手机 / 两种都用>拍。影片里我讲<语言>。
我<有一趟旅行要去 / 有一趟以前旅行的素材，想做成影片>。
```

想自己打指令也可以：`/plugin marketplace add yuxuanteh/vlog-studio`，再 `/plugin install vlog-studio@vlog-studio`，然后说「帮我设好 vlog 工作室」。

之后都是讲人话：「帮我规划去京都的行程」、「素材放进 raw 了」、「这是去年拍的素材，帮我做一支 vlog」、「这个镜头太晃，换一个」、「做成片」。

## 设定的时候会问你什么

1. **先检查你的电脑。** 给你一张表：每个步骤在你的电脑上大概要多久，1080p 成片和 4K 成片并排比。这些都在你做任何决定之前。
2. **横的、直的，还是两种都做？** 这会决定每一支影片怎么规划、怎么剪、做成多大。
3. **你发在哪里？** YouTube、YouTube Shorts、Instagram、Facebook、TikTok、小红书、哔哩哔哩，或其他。每个平台的长度上限、能不能放连结、封面怎么裁、按钮会挡住画面的哪里都不一样，所以每个平台各有一份文字。
4. **横的成片要 4K 还是 1080p**，连同各自在你电脑上要花的时间和硬盘空间一起告诉你。
5. **用相机还是手机拍？** 只用手机拍也完全可以。
6. **每一样工具，装之前都先讲**：做什么用、谁可以不装、有多大。
7. **用你自己的几段素材试跑**：素材总表、初剪、审片页和剪辑页，用你自己的语言、你自己相机的档案。

### 有哪些部分，谁可以不装

| 部分 | 它帮你做什么 | 什么情况可以不装 | 下载大小 |
|---|---|---|---|
| 核心 | 工作室自己的 Python、ffmpeg 和 ExifTool：素材总表、剪接、字幕、输出。也会自动稳住晃的镜头、把镜头之间的亮度拉齐（两样都可以关掉） | 一定要装 | 约 450 MB |
| 字体 | 字幕、地点标签、标题用的免费字体 | 一定要装 | 3 MB（英文等）到 45 MB（中文） |
| 语音识别（Whisper） | 在你自己的电脑上，把每一段素材里讲的话写下来。可以用讲的话找素材，剪点落在字和字之间，字幕对好时间 | 你的影片里没有人讲话 | 3.1 GB（最准）、1.7 GB（中）或 0.7 GB（小） |
| 隐私 | 在你用到的镜头里找出路人的脸，你每一个都决定过（保留、打码、不用）才会出片。也可以跟着一张车票或 QR code 把它打码 | 你从来不拍到别人，或者你自己会每个镜头看过 | 约 1 MB |
| 配乐对拍 | 把一首曲子照小节线缩短或加长，让它刚好停在自己的结尾 | 不要配乐，或在平台的 app 里才加音乐 | 约 300 MB |
| 缩略图去背 | 把你从画面里干净地抠出来，做缩略图和封面 | 用整张画面做缩略图就够了 | 约 1.2 GB |
| 精确对字 | 找出每个字确切的开始和结束，句子中间的剪点才干净 | 你不介意偶尔在剪辑页修一下被切到的字 | 约 3 GB |

全部装大约 8 GB；最小可用的组合（核心、字体、小的语音模型）大约 1.2 GB。

### 大概要多久

下面是在参考笔电上的时间（Intel Core Ultra 7 155H，16 核，16 GB 内存，没有独立显卡），素材是相机拍的 4K。设定时会量你自己的电脑，再照比例换算。

| 步骤 | 电脑要跑多久 |
|---|---|
| 每趟旅行一次，2 小时素材：把讲的话写下来（其中半小时有讲话） | 约 20 分钟 |
| 每趟旅行一次：看过全部素材（缩图总表、晃不晃、清不清楚） | 约 30 分钟 |
| 每趟旅行一次：720p 工作用的副本 | 约 40 分钟 |
| 一支 8 分钟影片的检查版（每一轮修改） | 约 20 分钟 |
| 这支影片的 1080p 成片 | 约 40 分钟 |
| 这支影片的 4K 成片 | 约 1 小时 45 分钟 |
| 一支 1 分钟的直式影片：检查版，然后成片 | 约 5 分钟和 10 分钟 |

这些是粗估，实际可能是一半到两倍。硬盘：一小时 4K 素材大约 45 GB（这是你的素材，放在你自己的地方）；工作室另外需要每小时素材约 1 GB 的工作副本，以及每分钟 4K 影片约 3 GB 的渲染暂存（1080p 是四分之一），一趟做完都可以删。

## 一支影片怎么做出来

一共九步。写着**停**的地方，Claude 会停下来等你点头。

1. **行程计划**（素材已经拍好的话跳过）。每个地方是什么，根据真正的资料；每个地方的拍摄清单；你在现场可以讲什么。**停。**
2. **你去拍。** 每天晚上录一段感想：去了哪里、什么让你意外、哪里出状况。这些感想就是旁白。
3. **素材总表和影片计划。** 每一段素材都写下来、量过晃不晃和清不清楚，每个地方排成一张总览图。你会收到：素材里有什么、缺什么、可以做成哪些影片、什么形状、给哪些平台。**停。**
4. **故事计划。** 每支影片一页，在动手剪之前：这支影片要回答的那一个问题、撑起它的三四个时刻、哪些不要、哪里停一下、配乐。**停。** 顺序在这里决定，因为这时候改不花成本。
5. **要补录的句子**，只补素材里没有的。**停。**
6. **你补录**，整趟旅行一次录完。
7. **初剪。** 你在**审片页**看、点意见，或者在**剪辑页**自己修字和字幕。**停。** 故事和节奏锁定。
8. **配乐、地点标签、隐私。** **停。**
9. **成片和上传包**：做好的档案、翻译字幕、封面，还有每个平台一段、各有各的文字。**停。** 上传和排程由你自己手动来。

### 从已经拍好的素材开始

「我有去年拍的素材，帮我做一支影片」也可以。流程从第 3 步开始，而且会先老实告诉你这些素材能做成什么。你已经分不出是哪里拍的片段，会用同一天的手机照片来对（手机照片有时间和地点）、用时间上的空档、用画面里的招牌来归位。如果没有旁白，会把画面一天一天排给你看，你对着讲几分钟，那段录音就是旁白。

## 每个工具用白话讲

| 工具 | 它是什么 |
|---|---|
| 素材总表（`footage_index.py`） | 每一段素材什么时候拍的、多长、在哪里、里面讲了什么；每个地方一张总览图 |
| 工作副本（`footage_proxy.py`） | 剪辑时用的 720p 小档；原档只有做成片时才读 |
| 晃动和清晰度（`clip_score.py`、`clip_motion.py`） | 每一段素材的每一秒都有数字，选镜头是看里面真正发生的事 |
| 对字（`word_index.py`、精确对字） | 你讲的每个字什么时候开始、什么时候结束，剪点才不会落在字中间 |
| 剪辑表 | 每支影片一个小档案：哪一段录音的哪几秒，配哪些镜头。Claude 照故事计划来写 |
| 总闸（`vlog_run.py`） | 出片只走这一个入口。自我测试、检查剪辑表、你的修改动到了什么又弄坏了什么、人脸、画面上的字跟你确认过的比对、成片之前先小尺寸排练一次，然后才渲染，旁边有看门的程序，卡住就停 |
| 审片页 | 在你自己电脑上的一个网页。播放、暂停、点一个现成的意见（「太短」、「镜头晃」、「换别的镜头」、「要打码」……）。每条意见会记下时间、镜头和当时的字幕 |
| 剪辑页 | 把你的声音变成一个个字。点一个字就可以剪掉或放回去，把字拖到下一句字幕，直接打字改字幕，在声音波形上拖一段剪掉语音识别没听到的「嗯」。你存的就是定案，不会被盖掉 |
| 字幕表 | 同样的修改也存成 Excel 档，习惯用表格的人可以直接改 |
| 隐私检查（`vlog_faces.py`） | 列出每一个认得出脸的镜头，每个你只要决定一次 |
| 稳定、亮度 | 晃的镜头自动稳住；同一个地方的镜头亮度拉齐；颜色保留你拍的样子 |
| 配乐对拍（`vlog_tracks.py`） | 只在小节线上剪，让曲子停在它自己的结尾；蒙太奇可以对着拍子剪 |
| 平台检查（`vlog_platform.py`） | 拿做好的档案、封面和文字，去对你发的每个平台的规则 |
| 缩略图（`vlog_thumbs.py`） | 从素材抓原尺寸的画面、把你抠出来、检查尺寸 |
| 设定工具（`probe.py`、`setup_studio.py`） | 量你的电脑、估时间；安装、检查、移除各个部分 |

## 平台

插件知道的规则都放在一个档案里（`platforms.toml`），每一条都写着上一次核对是哪个月。平台常常改规则，所以只要某个上限会影响决定，Claude 会先去看那个平台自己的说明页，再把档案改对。要加一个平台，复制一段来改就可以。

## 更新、清空间、换电脑、移除

直接跟 Claude 讲就好（「更新 Vlog Studio」、「帮我清硬盘空间」、「我换新电脑了」、「移除」），设定技能会处理，要删任何东西之前都会先问你。

- **更新：** `claude plugin marketplace update vlog-studio`，再 `claude plugin update vlog-studio@vlog-studio`。你的设定、平台规则、每一趟旅行、剪辑表和字幕表都不会被盖掉。
- **清空间：** 最占空间的是渲染暂存和已经做完的旅行的工作副本，需要时会重新做；任何可选的部分都可以先移除、以后再装。
- **换电脑：** 一趟旅行的东西都在它自己的资料夹里；在新电脑上重新跑一次设定。
- **移除：** 删掉工作室资料夹、移除插件。你的旅行资料夹是你的，不会动它。任何工具都不会搬动、改名或删除 `raw/` 里的档案。

## 需要什么

- Claude Code 和 Claude 的方案。
- Windows、macOS 或 Linux。在 Windows 11 上做出来、测过；macOS 和 Linux 用的是同一套程序，但还没测过，可能会遇到问题。
- 工作室本身 2 到 9 GB 硬盘空间，另外要留空间给工作副本和渲染暂存；内存 8 GB 以上（做 4K 建议 16 GB）。
- 一台相机或一支手机。另外买一支麦克风，比什么都有用。

## 它没有的

- 动画和手绘地图：这条流程以实拍素材为主。（要动画请用 Explainer Studio。）
- 自动写上传页的工具：由 Claude 照规则、每个平台各写一份。
- 自动发布：上传和排程由你自己来。
- 网页和表格有英文和中文两种。旁白可以是语音模型听得懂的任何语言；用得最多的是华语。英文字幕的断句规则比中文的简单，用得还很少。
